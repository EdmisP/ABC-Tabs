# Lithuania collection

- Noriu Miego: pre-existing project entry, preserved.
- Kalvelis_DG.abc: full D/G melody from https://trillian.mit.edu/~jc/music/abc/Intl/Kalvelis.abc (first musical entry). Added title, origin and source metadata.
- Klumpakojis_CF.abc: full C/F melody from https://trillian.mit.edu/~jc/music/abc/Intl/Klumpakojis.abc (first entry), transcription credited to John Chambers, 2009. Removed the redundant invalid inline key reset immediately before K:F; retained the music.
- Kalvelis_Kankles.abc: melody-only first part, transposed down seven semitones from the D/G source. Fits G3 A3 B3 C4 D4 E4 F#4 G4 (8 strings).
- Klumpakojis_Kankles.abc: melody-only introduction and first part, transposed down five semitones from the C/F source. Fits G3 A3 B3 C4 D4 E4 F#4 (7 strings).

The small-kankles entries are explicitly labelled partial adaptations. Full versions need additional accidentals/custom string tuning; they are not claimed to fit the default diatonic presets. Lyrics and newly composed accompaniment have not been added.

Source access: 2026-09-19. ABC entries are embedded in ../../lithuania-song-library.js so loading does not require a network request.
